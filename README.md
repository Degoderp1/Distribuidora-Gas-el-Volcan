# Distribuidora Gas El Volcán

Sitio web académico desarrollado para la **Distribuidora de Gas El Volcán**, empresa familiar ubicada en Chillán, Región de Ñuble.

## Descripción

El proyecto corresponde a una propuesta web para apoyar el proceso de pedidos y entrega de gas a domicilio. La interfaz incluye información de la empresa, catálogo de productos, formulario de pedido, contacto e inicio de sesión.

La solución busca facilitar que los clientes consulten productos y realicen solicitudes sin depender exclusivamente de llamadas telefónicas.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Diseño responsive

> **Nota:** El caso académico establece React para el frontend y Spring Boot para el backend. Esta versión corresponde a una implementación inicial/prototipo del frontend realizada con HTML, CSS y JavaScript.

## Funcionalidades principales

### Página principal
Presenta la empresa y acceso rápido a las principales secciones del sitio.

### Nosotros
Entrega información general sobre Distribuidora Gas El Volcán, su actividad y el propósito de la solución web.

### Catálogo
Muestra los productos disponibles mediante tarjetas generadas con JavaScript.

### Pedido
Permite agregar productos uno por uno a un pedido, modificar cantidades, eliminar productos y calcular el total automáticamente.

### Contacto
Contiene información básica para comunicarse con la distribuidora.

### Login
Incluye una pantalla de inicio de sesión como parte de la propuesta de sistema.

## Cómo ejecutar el proyecto

No requiere instalación de dependencias para esta versión.

1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto.
3. Abre `index.html` en un navegador web.
4. Navega por las diferentes secciones desde el menú.

También puedes utilizar **Visual Studio Code** con la extensión **Live Server** para ejecutar el sitio localmente.

## Contexto del proyecto

De acuerdo con el caso académico, Distribuidora de Gas El Volcán es una empresa familiar fundada en 1998 en Chillán que distribuye cilindros de gas licuado a domicilio a clientes residenciales y comerciales de Chillán y comunas aledañas.

El problema identificado es que el proceso actual depende de llamadas telefónicas, registros en cuadernos y listas en papel, lo que dificulta el seguimiento de pedidos y el control del stock.

La propuesta busca avanzar hacia un proceso digital donde los clientes puedan realizar pedidos y consultar su estado, mientras el personal pueda gestionar las solicitudes de manera centralizada.
